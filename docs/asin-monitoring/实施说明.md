# 北向 ASIN 监控：首版实施与试运行说明

更新：2026-10-25。对应需求文档：`北向ASIN监控需求设计V1.0.docx`。

本版已接入北向网站，可添加监控对象、采集公开商品字段、保存证据和查看前后差异。真实样本已验证；当前属于本地试运行版本，不能视为需求文档全部功能已验收。已接入专用 Amazon 登录会话用于具体评论；首次真实登录与评论实采验收待用户手动登录后完成。

## 使用方式

在项目目录运行 `npm start`，打开 `http://127.0.0.1:4317/#asin`。页面与检查服务随本地 Node 进程运行；休眠、断网或退出服务期间不会持续观察，也不能补出期间所有变化。

1. 点击“添加 ASIN”，输入美国站 ASIN 或详情页链接，也可从已有竞品档案的 Amazon 链接中选择。
2. 设置配送邮编、标签、价格检查周期、内容检查周期和价格提醒阈值。可先保存为暂停状态。
3. 首次成功取得的字段建立基线。后续同来源、同观察条件、同采集版本的数据才生成变化记录。
4. 点击商品进入变化时间线；展开记录即可查看变化前后值和差异。通过快照入口查看对应截图、提取原文和覆盖说明。
5. “当前数据”保留每个字段最近的有效值和观察时间。“快照对比”可选两个历史快照。“数值历史”包含价格折线及价格、评分、Rating 数量明细。
6. 可暂停、恢复、归档、人工复核、关注、添加备注、查看站内提醒和今日变化；变化导出 CSV，完整历史导出 JSON。

## 已实现范围

| 功能 | 首版行为 |
|---|---|
| 管理对象 | 美国站、最多 50 个非归档 ASIN；逐项导入结果、重复检查、关联既有品牌与商品链接 |
| 观察条件 | 公开字段：访客、非 Prime、USD、en-US、1440×1000、固定配送邮编；具体评论：独立登录会话，Prime 状态未观察，不用于报价 |
| 字段 | 售价、参考价、卖家/发货方、促销、可购买状态、标题、卖点、描述/规格、A+、图片、评分、Rating 数量、文字评论数量、星级分布、评论摘要、评论卡片 |
| 数字变化 | 精确数值的前值、后值、差值和百分比；`1.2K` 等近似表达保留原文，不推算精确增量 |
| 文案变化 | 原文左右对比；单段文字突出不同区间；卖点增加、删除、改写和排序可查看原始列表 |
| 图片变化 | 限定 Amazon 图片域、内容 SHA256、标准化像素 hash、当地图片证据；识别内容变化和排序变化 |
| 评论变化 | 按稳定 review ID 匹配进入、离开、换位和内容变化；片段差异不直接断言全文被编辑 |
| 证据 | 快照、当前字段、变化事件、运行记录、页面截图、区域截图、提取原文和图片资产持久化 |
| 运行 | PostgreSQL 队列、单任务并发、任务租约、进程中断恢复、失败退避、人工重试冷却、每日次数上限 |
| 防误报 | 未取得/失败不覆盖旧值；不把空字段变成零价或删除；首次取得、来源变化、观察条件变化、采集版本变更建立新基线 |
| 提醒 | 站内变化提醒及当日汇总；价格阈值只控制提醒，低于阈值的变化仍保留；评分下降和未展示等变化按后续观察复核 |

字段列在这里表示系统支持存储、展示和比较，不表示每个 Amazon 页面都能稳定取得该字段。每次采集都会记录实际覆盖及未取得原因。

## 真实采集验证

2026-10-25，以已有竞品档案中的 Echo Dot Max（`B0D6SX8VLQ`）作真实样本，配送邮编 `60202`。

第二次真实检查取得 13 / 16 个字段：售价、参考价、优惠条件、可购买状态、标题、7 条卖点、描述/规格、A+、7 张商品图片、评分、Rating 数量、星级分布、评论摘要。证据保存在本地数据库与证据目录；验证摘要见 `work/asin-monitor-implementation/live-validation.json`。

此页面实际返回“Sign in to see customer reviews”，因此评论卡片标为未取得，未生成空评论列表或评论删除事件。卖家/发货方及独立文字评论数量在该次检查中也未成功取得。Rating 数量与文字评论数量从未混用。

初版与修正后采集器之间改变了提取口径；该次迁移建立新基线，没有把解析适配产生的差异当作商品变化。试验用的虚构 ASIN 与快照会从正式数据库清除，只保留真实样本。

## 仍需完成或明确的范围

- **具体评论实采**：用户已选择专用 Amazon 登录会话，接入与测试完成；需要用户手动登录，再验证 Amazon 实际展示的评论。当前尚不能宣称真实评论自动采集已验收。
- **页面覆盖验证**：已实测一个 Amazon 自营设备 ASIN，尚未完成多类目、多品牌、多变体及连续 7 天稳定性验收。页面访问验证、缺字段、异步加载和布局变化仍可能使任务部分成功或失败。
- **优惠消失判断**：没有明确证据时，找不到优惠组件会记录 unknown，不能保证自动识别所有优惠结束；人工导入可用 absent 表达确认未展示。没有推算组合优惠后的实际结算价。
- **图片覆盖**：主图/附图最多 15 张，A+ 最多 30 张；不覆盖视频、交互轮播的全部隐藏内容或所有浏览器视口；像素 hash 尚未加入完整感知相似度审核，细微压缩变化仍需人工核对。
- **评论覆盖**：最多 80 个详情页当次展示的评论卡片，不能推出全量评论的增删。评分和 Rating 数量是页面展示口径，可能由变体合并；系统不推断隐藏的父体聚合关系。
- **站点与运行方式**：尚未支持其他国家站、多 Prime 身份/多个登录账户/地区多配置并行、云端常驻采集、付费采集服务和故障渠道推送。
- **后续产品能力**：XLSX/HTML 报告、外部通知渠道、自动证据保留期与磁盘清理、多用户权限、全局跨商品复杂筛选、竞品旧价格面板的统一数据适配尚未实现。现有竞品手工价格历史没有被重新解释成自动采集历史。

## 专用 Amazon 评论登录会话（2026-10-25 补充）

已按用户选择接入专用会话。入口在监控清单和 ASIN 详情的“管理登录会话”。

1. 点击“打开专用登录窗口”，会打开独立的 Chromium。用户在 Amazon 美国站自行输入账号、密码和验证码。
2. 登录完成后回到 Amazon 美国站首页，再回北向点击“验证并启用”。只有公开导航区域能明确确认登录状态时才启用；没有明确证据时仍保持待处理。
3. 验证通过后关闭独立窗口，写入本机浏览器配置，并将启用中且未阻塞的 ASIN 内容检查设为到期。实际执行仍受队列和每日额度控制。
4. 详情中把“数据来源”切换成“专用会话评论”，查看当前评论、历史快照、前后对比和变化时间线。该来源只包含评论展示及明确标注的文字评论数量；不写入价格、评分或 Rating 数量。
5. 登录过期或 Amazon 要求人工访问验证时，显示需要处理，停止该专用会话的自动使用。访客字段继续采集，旧评论及其时间保留。重新打开专用窗口并验证即可继续。

评论取详情页默认排序下实际出现的卡片，最多 80 条。卡片包含稳定 ID、位置、区域、标题、正文/片段、星级、日期、变体、Verified Purchase、Vine 和 helpful 文本。离开展示区不等于删除；不主动翻页、不声称全量评论，也不通过点击购买、改变账户资料或绕过访问验证取得数据。解析布局尚需在用户登录后实测。

**来源与比较规则**：公开采集标记为 `browser`，专用会话评论为 `browser-auth`，人工导入为 `manual`。三种来源的快照、当前值和变化独立。专用评论观察条件包含配送邮编、语言、视口、默认展示及会话批次；每次打开登录/修复窗口生成新批次。即使仍是同一账号，也保守地重建评论基线，避免个性化展示变化成为商品变化。跨批次快照禁止直接比较；旧会话快照保留可查。第一次有效取得评论不会产生变更提醒。

**数据保存**：登录配置只在 `.runtime/asin-amazon-session/profile/`；父目录及配置目录权限为 `0700`。`session.json` 只保存状态、匿名批次、验证时间和固定提示语，权限 `0600`。不读取或导出 Cookie、密码和验证码，也不复用日常 Chrome。评论证据仅保存提取后的商品评论 JSON，不保存登录页面截图、完整 HTML、导航账号名或地址。`.runtime/` 已在 `.gitignore` 中；备份项目时应排除该登录目录。

**窗口与并发**：手动登录窗口打开期间，自动评论检查让出会话；价格等公开检查继续。服务拥有该专用窗口，通过独立数据库锁避免多个进程同时打开同一配置目录。关闭窗口但未点验证，不会启用采集；重启服务后需重新打开并验证。验证后的会话可跨服务重启保留，但每次评论采集都重新确认登录证据。停用会话会暂停评论自动使用，保留本机登录配置及历史数据。

**验证状态**：本轮共 46 项自动测试通过（含原功能回归），桌面及 390 px 手机登录入口和评论来源切换验证通过，浏览器控制台无错误。新增自动测试覆盖手动登录流程、未登录拒绝、验证后关闭、目录权限、跨进程互斥、会话失效与修复、源隔离、新批次基线、跨批次比较拒绝、缺失保护和账号信息不外泄。真实账号登录和具体评论实采仍待用户操作后验证。

## 运行与维护

运行环境：Node.js 22、PostgreSQL、`playwright-core` 1.62.1、`sharp` 0.35.5，以及与 Playwright 匹配的隔离 Chromium。安装匹配浏览器可运行 `npx playwright-core install chromium`。本机已存在匹配浏览器。

- 默认周期：价格/促销每 4 小时；内容、图片、评分与评论每 24 小时。
- 每日默认上限 350 次，按北京时间自然日计；页面可修改为 1–1000 次。每次尝试有独立计数。
- 同一 ASIN 手动检查至少间隔 5 分钟。访问验证/限流暂停该对象；一般失败 5 / 20 分钟退避，连续 3 次失败后等待处理。
- 同一服务内单个浏览器任务运行，通过 PostgreSQL advisory lock 避免多进程重复执行。服务重启后恢复未完成队列；租约最长等待约 6 分钟。
- `ASIN_WORKER_DISABLED=1` 可关闭该服务进程的检查器，保留读写 API；测试服务使用此变量。另一个已运行进程仍可能持有同一数据库的检查器。
- `ASIN_CHROMIUM_PATH` 可指定隔离 Chromium 可执行路径。不能指向日常使用的 Chrome 用户数据目录；公开字段每次检查使用临时访客上下文；评论使用专用持久化目录。
- 数据库表以 `asin_` 开头。证据目录为 `.runtime/asin-evidence`。没有自动删除策略，持续运行前需要监测磁盘占用并配置后续保留策略。
- 本轮开发前数据库备份：`.runtime/before-asin-monitor.dump`；源文件备份：`.runtime/before-asin-monitor-src.tgz`。恢复备份会覆盖之后的业务修改，不能在不了解当前数据状态时直接恢复。

## 人工快照格式

从商品详情中的“导入快照”打开模板。文件必须标明目标 ASIN、US 站点、与当前配置一致的观察条件和真实观察时间。示例只用于解释结构，不能作为商品事实导入：

```json
{
  "asin": "目标十位ASIN",
  "marketplace": "US",
  "profile": {"zip": "60202"},
  "observed_at": "真实观察时间（ISO 8601，含时区）",
  "fields": {
    "sale_price": {"state": "observed", "value": 89.99, "currency": "USD"},
    "title": {"state": "observed", "value": "实际观察的商品标题"},
    "promotions": {"state": "absent", "value": null, "reason": "人工完整核对后确认未展示"},
    "rating_count": {"state": "observed", "value": null, "precision": "approximate", "raw": "1.2K ratings"},
    "reviews": {"state": "unknown", "value": null, "reason": "评论区域需要登录"}
  }
}
```

人工导入始终标记为 manual。文件中的 browser 来源声明会被忽略，不能伪造页面采集身份或引用其他 ASIN 的证据。导入旧时间快照会保留历史，不会把当前有效值倒退。
